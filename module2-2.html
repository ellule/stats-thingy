2.2 - Les mesures de tendance centrale

La moyenne, la médiane et le mode

Introduction

Les mesures de tendance centrale servent à représenter un ensemble de données avec une valeur typique. Elles nous aident à mieux comprendre et à comparer des données statistiques.

Il existe trois mesures principales :

  • La moyenne : la somme des valeurs divisée par le nombre de valeurs.
  • La médiane : la valeur située au milieu des données ordonnées.
  • Le mode : la valeur qui apparaît le plus souvent.

1. La moyenne

La moyenne arithmétique est obtenue en additionnant toutes les valeurs et en divisant le résultat par le nombre total de valeurs.

\[ \bar{x}=\frac{\displaystyle\sum_{i=1}^{n}x_i}{n} \]

Dans cette formule, \(x_i\) représente chaque valeur, \(n\) représente le nombre total de valeurs et \(\bar{x}\) représente la moyenne.

Exemple

Voici les notes de cinq élèves :

2, 3, 3, 5, 7

On additionne les cinq valeurs, puis on divise par 5 :

\[ \bar{x}=\frac{2+3+3+5+7}{5} =\frac{20}{5}=4 \]

La moyenne est 4.

À retenir : la moyenne utilise toutes les valeurs, mais elle peut être influencée par une valeur extrêmement élevée ou faible.

2. La médiane

La médiane est la valeur qui se trouve au milieu d'un ensemble de données lorsque les valeurs sont placées en ordre croissant ou décroissant.

Étape 1 : placer les données en ordre.
Étape 2 : déterminer la position de la médiane.

Lorsque le nombre de valeurs est impair

\[ \text{Position de la médiane}=\frac{n+1}{2} \]

Cette formule donne la position de la médiane, et non directement sa valeur.

Exemple avec un nombre impair de valeurs

Les données sont déjà en ordre :

2, 3, 3, 5, 7

Il y a 5 valeurs. La position de la médiane est :

\[ \frac{5+1}{2}=3 \]

La médiane est donc la troisième valeur, soit 3.

Lorsque le nombre de valeurs est pair

Lorsqu'il y a un nombre pair de valeurs, on calcule la moyenne des deux valeurs centrales.

2, 4, 6, 8, 10, 12

\[ \text{Médiane}=\frac{6+8}{2}=7 \]

La médiane est 7.

Vidéo explicative

À retenir : il faut toujours ordonner les données avant de déterminer la médiane. Elle est généralement moins influencée par les valeurs extrêmes que la moyenne.

3. Le mode

Le mode est la valeur qui apparaît le plus souvent dans un ensemble de données.

Exemple

2, 3, 3, 5, 7

La valeur 3 apparaît deux fois, alors que les autres valeurs apparaissent une seule fois.

Le mode est 3.

Quelques possibilités

  • Un mode : une seule valeur apparaît le plus souvent.
  • Deux modes ou plus : plusieurs valeurs sont à égalité pour la fréquence la plus élevée.
  • Aucun mode : aucune valeur n'apparaît plus souvent que les autres.

Vidéo explicative

À retenir : le mode est particulièrement utile pour identifier la valeur la plus fréquente, comme la pointure la plus vendue dans un magasin ou le moyen de transport le plus utilisé.

4. Comparaison des trois mesures

Mesure Comment la trouver Point important
Moyenne Additionner les valeurs et diviser par leur nombre. Sensible aux valeurs extrêmes.
Médiane Ordonner les données et trouver le milieu. Moins influencée par les valeurs extrêmes.
Mode Repérer la valeur la plus fréquente. Peut avoir plusieurs modes ou aucun mode.

Exemple récapitulatif

Pour les données suivantes :

2, 3, 3, 5, 7

  • Moyenne : 4
  • Médiane : 3
  • Mode : 3

Les trois mesures décrivent le même ensemble de données, mais chacune apporte une information différente.
