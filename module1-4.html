Les sources de données

Sources de données primaires

Les sources de données primaires sont des données recueillies directement par la personne qui réalise une étude ou une recherche. Ces données peuvent être recueillies à l'aide de sondages, d'entrevues, d'observations ou d'expériences.

Notes de cours sur les sources de données primaires

Sources de données secondaires

Les sources de données secondaires sont des données qui ont déjà été recueillies par une autre personne ou une autre organisation. Ces données peuvent être utilisées pour faire une nouvelle recherche ou pour analyser une situation.
