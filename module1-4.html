1.4 - Les sources de données

Sources de données primaires

Les sources de données primaires sont des données recueillies directement par une personne ou une organisation dans le but de répondre à une question précise.

Voir les notes de cours sur les sources de données primaires

Sources de données secondaires

Les sources de données secondaires sont des données qui ont déjà été recueillies par une autre personne ou une organisation et qui peuvent être utilisées pour une nouvelle étude ou analyse.
