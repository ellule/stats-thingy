1.1 - Représentation des données

Les différents types de données

Variable Quantitative (continue et discrète)

Une variable quantitative est une caractéristique mesurable qui s'exprime par un nombre ou une quantité. [Allo prof] Exemples par moi : - Continue : peut prendre n’importe quelle valeur dans un intervalle, y compris des décimales. Exemple : la taille d’une personne (165,5 cm). - Discrète : peut prendre seulement des valeurs précises et séparées, généralement des nombres entiers. Exemple : le nombre de frères et sœurs (0, 1, 2, 3...).

Variable Qualitative (nominale et ordinale)

Une variable qualitative (ou catégorique) exprime une qualité ou une catégorie qui ne se mesure pas avec un nombre. Ses différentes valeurs possibles sont appelées des modalités. [Statistique Canada] Exemples par moi : - Nominale : les catégories n’ont pas d’ordre particulier. Exemple : la couleur des yeux (bleu, brun, vert, etc.). - Ordinale : les catégories peuvent être classées dans un ordre, mais la différence entre les catégories n’est pas mesurée précisément. Exemple : le niveau de satisfaction (insatisfait, neutre, satisfait, très satisfait).

Certains types de diagrammes

Diagramme à bandes

Un diagramme à bandes utilise des barres pour comparer différentes catégories de données. Les barres sont séparées les unes des autres. On l’utilise pour comparer des catégories, par exemple le nombre d’élèves qui préfèrent différents sports.

Histogramme

Un histogramme utilise des barres collées les unes aux autres pour représenter des données quantitatives regroupées en intervalles. On l’utilise pour montrer la distribution de données, par exemple les résultats d’un test ou l’âge des élèves.

Diagramme circulaire

Un diagramme circulaire est un cercle divisé en sections qui représentent des parties d’un total. On l’utilise pour montrer les proportions ou les pourcentages d’un ensemble, par exemple le pourcentage d’élèves qui préfèrent différents types de musique.

Diagramme à ligne brisée

Un diagramme à ligne brisée utilise des points reliés par des lignes pour montrer comment une donnée change, souvent au fil du temps. On l’utilise pour montrer une tendance, par exemple l’évolution de la température pendant une semaine.
